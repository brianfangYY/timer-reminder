# ⏰ timer-reminder

单机版 Android 定时提醒软件 | 卡通儿童风格

## 项目概况

| 项目 | 内容 |
|------|------|
| 平台 | Android 7.0+ |
| 开发语言 | Kotlin |
| 数据库 | 本地 SQLite |
| 版本控制 | Git + GitHub |
| 状态 | 需求分析阶段 ✅ |

## 功能模块

- ⏰ 日常提醒（喝水、吃药、休息）
- 🍅 番茄钟（专注25分钟 + 休息5分钟）
- 🔔 多闹钟管理
- 📋 任务事件提醒
