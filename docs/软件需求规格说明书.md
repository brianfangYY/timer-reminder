## 1. 引言

### 1.1 编写目的
本文档旨在明确「timer-reminder」单机版定时提醒软件的功能需求、性能需求、外部接口及界面要求，为后续的概要设计、详细设计、编码实现和测试验收提供依据。

### 1.2 项目范围
本软件为一款运行于 Android 平台的单机版定时提醒工具，无需网络连接，所有数据本地存储。

### 1.3 术语与定义

| 术语 | 定义 |
|------|------|
| APK | Android Application Package，安卓应用安装包 |
| 番茄钟 | 一种时间管理方法，25分钟专注 + 5分钟休息 |
| 本地存储 | 数据保存在手机本地，不涉及云端同步 |

## 2. 项目概述

### 2.1 产品背景
用户需要一个适合儿童使用的卡通风格定时提醒工具，帮助管理日常作息、学习和任务安排。

### 2.2 产品功能概要

| 编号 | 功能模块 | 说明 |
|------|---------|------|
| F-01 | 日常提醒 | 设置喝水、吃药、休息等周期性提醒 |
| F-02 | 番茄钟 | 专注倒计时 + 休息倒计时，可自定义时长 |
| F-03 | 闹钟管理 | 支持创建、编辑、删除多个闹钟 |
| F-04 | 任务事件提醒 | 针对具体任务设置提醒时间 |

### 2.3 用户特征
- 主要用户：儿童及家长
- 使用场景：学习时间管理、日常作息提醒
- 技术要求：界面简单直观，无需复杂操作

### 2.4 运行环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Android 7.0（API 24）及以上 |
| 网络 | 无需网络，纯单机运行 |
| 存储 | 本地 SQLite 数据库 |

## 3. 具体需求

### 3.1 功能需求

#### F-01 日常提醒

| 需求项 | 描述 |
|--------|------|
| F-01.1 | 用户可创建日常提醒，选择类型（喝水/吃药/休息/自定义） |
| F-01.2 | 支持设置提醒时间（时:分）和重复周期（每天/工作日/自定义） |
| F-01.3 | 提醒到达时，弹出通知并播放铃声 |
| F-01.4 | 支持标记提醒为「已处理」或「稍后提醒」 |

#### F-02 番茄钟

| 需求项 | 描述 |
|--------|------|
| F-02.1 | 默认专注25分钟 + 休息5分钟，用户可自定义时长 |
| F-02.2 | 倒计时显示剩余时间（时:分:秒），带进度条动画 |
| F-02.3 | 专注结束后自动进入休息倒计时，反之亦然 |
| F-02.4 | 支持暂停/继续/停止操作 |
| F-02.5 | 当天完成的番茄数统计 |

#### F-03 闹钟管理

| 需求项 | 描述 |
|--------|------|
| F-03.1 | 支持创建多个闹钟，每个闹钟独立设置时间 |
| F-03.2 | 支持开启/关闭单个闹钟 |
| F-03.3 | 支持编辑和删除已有闹钟 |
| F-03.4 | 支持设置闹钟的铃声和音量 |
| F-03.5 | 闹钟响铃时支持「稍后提醒」（5分钟后重响）和「关闭」 |

#### F-04 任务事件提醒

| 需求项 | 描述 |
|--------|------|
| F-04.1 | 用户可创建任务/事件，填写标题和备注 |
| F-04.2 | 支持设置任务的提醒时间 |
| F-04.3 | 支持标记任务为「已完成」 |
| F-04.4 | 支持查看任务列表（今日/全部/已完成） |
| F-04.5 | 支持编辑和删除任务 |

### 3.2 界面需求

#### UI-01 整体风格

| 需求项 | 描述 |
|--------|------|
| UI-01.1 | **卡通儿童风格**，圆角设计，色彩明亮柔和 |
| UI-01.2 | 主色调用暖色系（橙色、黄色、淡蓝色），背景白色或浅色 |
| UI-01.3 | 按钮采用圆角大按钮，配有可爱图标 |
| UI-01.4 | 字体偏大，适合儿童阅读 |
| UI-01.5 | 所有页面配有卡通小动物或星星等装饰元素 |

#### UI-02 页面结构

| 页面 | 内容 |
|------|------|
| 首页 | 显示四个功能入口卡片（日常提醒 / 番茄钟 / 闹钟 / 任务），配卡通图标 |
| 日常提醒页 | 提醒列表 + 添加按钮，每个提醒项带开关 |
| 番茄钟页 | 大倒计时显示 + 暂停/停止按钮，下方显示历史记录 |
| 闹钟页 | 闹钟列表 + 添加按钮，每个闹钟项带开关 |
| 任务页 | 任务列表 + 添加按钮，可切换视图 |

### 3.3 性能需求

| 需求项 | 描述 |
|--------|------|
| P-01 | 应用启动时间不超过 3 秒 |
| P-02 | 提醒响铃延迟不超过 1 秒 |
| P-03 | 后台运行时提醒必须正常触发 |
| P-04 | 应用占用内存不超过 100MB |

### 3.4 数据存储

| 需求项 | 描述 |
|--------|------|
| D-01 | 所有数据存储于本地 SQLite 数据库 |
| D-02 | 数据库表：reminders（日常提醒）、tasks（任务事件）、alarms（闹钟）、tomato_records（番茄钟记录） |
| D-03 | 数据持久化，应用关闭后不丢失 |

### 3.5 可靠性需求

| 需求项 | 描述 |
|--------|------|
| R-01 | 应用崩溃率不超过 1% |
| R-02 | 提醒必须保证在设定时间触发，即使应用在后台 |
| R-03 | 数据库操作需使用事务保证数据一致性 |

## 4. 外部接口需求

### 4.1 用户接口
- 触控操作：点击、长按、滑动
- 通知栏：Android Notification 推送提醒信息
- 闹钟服务：Android AlarmManager 或 WorkManager 保证后台提醒

### 4.2 软件接口
- Android 系统通知服务
- 媒体播放服务（闹钟铃声播放）

### 4.3 硬件接口
- 扬声器（播放铃声）
- 振动器（可选振动提醒）
