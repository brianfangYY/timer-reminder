## 2. 总体设计

### 2.1 技术选型

| 类别 | 技术方案 | 选型理由 |
|------|---------|---------|
| 开发语言 | Kotlin | Google 推荐的 Android 开发语言，语法简洁，空安全 |
| 架构模式 | MVVM + Repository | 官方推荐架构，职责清晰，易于测试和维护 |
| UI 框架 | Jetpack Compose | 声明式 UI，代码量少，易于实现卡通风格动画 |
| 数据库 | Room (SQLite 封装) | Google 官方 ORM，编译时校验 SQL，支持协程 |
| 后台提醒 | AlarmManager + WorkManager | 系统级定时服务，保证提醒准时触发 |
| 依赖注入 | Hilt | 官方 DI 框架，减少样板代码 |
| 异步编程 | Kotlin Coroutines + Flow | 轻量级异步方案，配合 Room 和 ViewModel |
| 构建工具 | Gradle + Kotlin DSL | 官方构建系统 |
| 最低版本 | Android 7.0 (API 24) | 覆盖绝大多数 Android 设备 |
| 编译版本 | Android 14 (API 34) | 最新的稳定 API |

## 3. 模块详细设计

### 3.1 首页模块

**功能：** 展示四个功能入口卡片，引导用户进入各功能页面

**页面元素：**
- 顶部：卡通主题标题（含动画装饰）
- 中部：4 张卡片，每张包含卡通图标 + 功能名称
- 底部：可爱的装饰元素

**交互逻辑：**
| 操作 | 结果 |
|------|------|
| 点击「日常提醒」卡片 | 跳转到提醒页面 |
| 点击「番茄钟」卡片 | 跳转到番茄钟页面 |
| 点击「闹钟」卡片 | 跳转到闹钟页面 |
| 点击「任务」卡片 | 跳转到任务页面 |

### 3.2 日常提醒模块

**功能：** 管理周期性提醒的创建、编辑、删除和开关

**数据模型：**
```
ReminderEntity:
  - id: Long (PK, 自增)
  - title: String (提醒标题)
  - type: String (喝水/吃药/休息/自定义)
  - hour: Int (提醒小时)
  - minute: Int (提醒分钟)
  - repeatType: String (每天/工作日/自定义)
  - repeatDays: List<Int> (自定义重复的天数，1-7)
  - isEnabled: Boolean (是否启用)
  - ringtoneUri: String (铃声路径)
  - createdAt: Long (创建时间戳)
```

**核心逻辑：**
- 添加提醒 → 写入 Room 数据库 → 注册 AlarmManager
- 编辑提醒 → 更新数据库 → 取消旧 Alarm → 注册新 Alarm
- 删除提醒 → 删除数据库 → 取消 AlarmManager
- 开关提醒 → 更新 isEnabled → 根据状态注册/取消 AlarmManager
- 提醒触发 → AlarmManager 发出广播 → BroadcastReceiver 弹出通知

### 3.3 番茄钟模块

**功能：** 专注计时 + 休息计时，可自定义时长

**数据模型：**
```
TomatoRecordEntity:
  - id: Long (PK, 自增)
  - focusDuration: Int (专注时长，默认25分钟)
  - breakDuration: Int (休息时长，默认5分钟)
  - startTime: Long (开始时间戳)
  - endTime: Long (结束时间戳)
  - type: String (focus/break)
  - isCompleted: Boolean (是否完成)
  - date: String (日期，格式 yyyy-MM-dd)
```

**核心逻辑：**
- 启动番茄钟 → 创建记录 → 启动倒计时
- 倒计时通过 `CountDownTimer` + 前台服务保活
- 专注完成 → 自动切换休息模式 → 发出通知
- 休息完成 → 标记一轮番茄完成 → 等待用户开启下一轮
- 数据统计：当日完成番茄数 = 当日 isCompleted=true 的记录数

### 3.4 闹钟管理模块

**功能：** 管理多个独立闹钟

**数据模型：**
```
AlarmEntity:
  - id: Long (PK, 自增)
  - label: String (闹钟标签)
  - hour: Int (小时)
  - minute: Int (分钟)
  - isEnabled: Boolean (是否启用)
  - ringtoneUri: String (铃声路径)
  - isVibrate: Boolean (是否振动)
  - snoozeDuration: Int (稍后提醒间隔，默认5分钟)
  - createdAt: Long (创建时间戳)
```

**核心逻辑：**
- 使用 AlarmManager 的 `setRepeating()` 或 `setExactAndAllowWhileIdle()`
- 闹钟响铃 → 弹出全屏通知 Activity
- 点击「关闭」→ 取消通知
- 点击「稍后提醒」→ 5分钟后重新触发
- 系统重启后 → BootReceiver 重新注册所有已启用的闹钟

### 3.5 任务事件模块

**功能：** 创建任务并设置提醒

**数据模型：**
```
TaskEntity:
  - id: Long (PK, 自增)
  - title: String (任务标题)
  - note: String (备注/描述)
  - remindTime: Long? (提醒时间戳，可为空)
  - isCompleted: Boolean (是否已完成)
  - completedAt: Long? (完成时间戳)
  - priority: Int (优先级，1-3)
  - categoryId: Long? (分类ID)
  - createdAt: Long (创建时间戳)
  - updatedAt: Long (更新时间戳)
```

**核心逻辑：**
- 创建任务时若设置了提醒时间 → 注册一次性 AlarmManager
- 任务提醒触发 → 弹出通知
- 任务完成后 → 标记 isCompleted=true → 取消关联的提醒
- 支持按「今日/全部/已完成」视图筛选

### 4.2 SQLite 建表语句

```sql
-- 日常提醒表
CREATE TABLE reminders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    type TEXT NOT NULL DEFAULT '自定义',
    hour INTEGER NOT NULL,
    minute INTEGER NOT NULL,
    repeatType TEXT NOT NULL DEFAULT '每天',
    repeatDays TEXT,  -- JSON数组 [1,2,3,4,5,6,7]
    isEnabled INTEGER NOT NULL DEFAULT 1,
    ringtoneUri TEXT,
    createdAt INTEGER NOT NULL
);

-- 番茄钟记录表
CREATE TABLE tomato_records (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    focusDuration INTEGER NOT NULL DEFAULT 25,
    breakDuration INTEGER NOT NULL DEFAULT 5,
    startTime INTEGER NOT NULL,
    endTime INTEGER,
    type TEXT NOT NULL DEFAULT 'focus',  -- 'focus' 或 'break'
    isCompleted INTEGER NOT NULL DEFAULT 0,
    date TEXT NOT NULL  -- yyyy-MM-dd
);

-- 闹钟表
CREATE TABLE alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    label TEXT NOT NULL,
    hour INTEGER NOT NULL,
    minute INTEGER NOT NULL,
    isEnabled INTEGER NOT NULL DEFAULT 1,
    ringtoneUri TEXT,
    isVibrate INTEGER NOT NULL DEFAULT 1,
    snoozeDuration INTEGER NOT NULL DEFAULT 5,
    createdAt INTEGER NOT NULL
);

-- 任务表
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    note TEXT,
    remindTime INTEGER,
    isCompleted INTEGER NOT NULL DEFAULT 0,
    completedAt INTEGER,
    priority INTEGER NOT NULL DEFAULT 2,
    createdAt INTEGER NOT NULL,
    updatedAt INTEGER NOT NULL
);
```

## 6. 运行设计

### 6.1 运行模块组合

| 场景 | 组合 |
|------|------|
| 普通使用 | UI 层 + ViewModel + Repository + Database |
| 提醒触发 | AlarmManager → BroadcastReceiver → NotificationManager |
| 番茄钟进行 | UI 层 + CountDownTimer + 前台 Service |
| 系统重启 | BootReceiver → 重新注册所有启用的提醒和闹钟 |

### 6.2 运行控制
- 应用启动 → MainActivity → 初始化 Hilt DI → 初始化 Room DB → 加载首页
- 后台运行 → 通过前台 Service 保活（番茄钟模式），其余使用 AlarmManager
- 应用关闭 → 闹钟和提醒不受影响（AlarmManager 独立运行）

### 6.3 运行时间
- 前台 UI 响应：< 200ms
- 提醒触发延迟：< 1s（AlarmManager 保证）
- 番茄钟倒计时精度：每秒刷新

## 8. 出错处理设计

### 8.1 用户操作错误

| 场景 | 处理方式 |
|------|---------|
| 闹钟时间设置无效 | Toast 提示「请选择有效时间」 |
| 提醒标题为空 | 自动填入默认名称 |
| 番茄钟进行中又点开始 | 提示「当前番茄钟正在计时」 |

### 8.2 系统异常处理

| 异常 | 处理方式 |
|------|---------|
| 数据库写入失败 | 重试 3 次，仍失败则记录日志并提示用户 |
| AlarmManager 注册失败 | 记录日志，下次启动时重试 |
| 应用崩溃 | 借助 Crashlytics 或自定义异常处理器记录日志 |
| 权限不足（通知） | 引导用户到设置页开启通知权限 |

### 8.3 后台提醒保证
- 注册 `BOOT_COMPLETED` 广播，开机后重新注册所有提醒
- 启用 `SCHEDULE_EXACT_ALARM` 权限请求
- Android 12+ 对精确闹钟的限制处理（引导用户手动授权）
